# Keyboard Key Art Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the bottom-right hint pill with keyboard keys drawn where the action is (DOWN under the pourer with a refill ring, SPACE under the glass when a serve would go through, UP/LEFT garnish keys beside the glass), after reframing the view so the keys sit on the counter front.

**Architecture:** The camera zooms out to 1.65 and moves down; the background grows a counter front; the timer pill moves top right. `Main` gains the rule queries (`can_serve_now()`, `garnish_keys()`, `hold_down`) and drops `hint_text()`. A new `KeyHints` control in the HUD holds `Keycap` controls and, each tick, reads those queries (`sync(main)`) to decide which keys show, where, and in what state; only the pop/shrink/press/glide motion is tweened.

**Tech Stack:** Godot 4.5.1, GDScript, headless checks (`tools/run_check.gd`), headless Chrome for the background.

**Spec:** `docs/superpowers/specs/2026-10-18-key-art-design.md`

## Review Focus

1. Space pressed mid-pour (key hidden): the serve queues, the key must not pop up before the serve fires, and the next glass arrives empty with no SPACE (Task 3, check_keys `_space_rules`).
2. A drink change: the DOWN key glides to the new pourer and shows dim (not the ring) while it arrives / is corked (Task 4, check_keys `_down_key_states`).
3. Round end: no keys during SHOP_DELAY, the shop, or the next INTRO; DOWN pops in only when PLAYING starts (Tasks 3–4).
4. A refill starting with liquid in the glass: SPACE hides for the whole refill (pourer busy) and returns after (Task 3, `_space_rules`).
5. A garnish falling: SPACE hidden until it lands; with ice added and lime not, only LEFT shows (Task 3, `_garnish_rules`).

  - `class_name KeyHints extends Control` (full rect, mouse ignored): `var down: Keycap`, `var space: Keycap`, `var garnish_caps := {}` (Key → Keycap, created on first need); `func sync(main: Main) -> void`; `func press_garnish(key: Key) -> void`; `func cap_rect(cap: Keycap) -> Rect2` (HUD rect, for checks).

- Placement (HUD units, all from `main.world_to_hud`): key row top = `world_to_hud(Vector2(0, Main.COUNTER_LIP_Y)).y + 5`; DOWN centred at `world_to_hud(Pourer.rest_center(main.drink, Main.GLASS_POS + main.drink.pourer_offset)).x` (tweened over `Arrival.ARRIVE_TIME` when that x changes while shown, set directly otherwise); SPACE centred at `world_to_hud(Main.GLASS_POS).x`; UP centred on the glass's x with its bottom edge 8 units above `world_to_hud(lip).y` (`lip = GLASS_POS + drink.pourer_offset`); LEFT with its right edge 7 units left of the bracket spine (`world_to_hud(Vector2(glass.global_position.x + glass.bracket_x(), 0)).x`) and its top 4 units below the rim (`glass.rim_y_world()`).
