# Beer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add beer, a third drink with foam, a glass that tips while you pour, a slow ease-out bottle return and a new bottle per glass, sold for 150 after round 3.

**Architecture:** Beer is data (`drinks/beer.tres`) plus new `DrinkDef` fields that default to "off", so water and wine run exactly the old code paths. Foam is a small pure class (`Foam`) owned by the glass. The tipped glass stays in its own local pixel-column frame. A level surface becomes a sloped line there, and its height for a volume is solved over the existing column runs (exactly `level_for` at tilt 0). The tilt is drawn by turning the glass's draw layers about the mouth, the way the arrival lean already turns them. The stream and Main use tilt-aware glass helpers only while the glass is tipped.

**Tech Stack:** Godot 4.5.1, GDScript; headless checks through `tools/run_check.gd`; `--sweep` tuning tables; windowed `--shots` for visuals.

**Spec:** `docs/superpowers/specs/2026-10-18-beer-design.md`

## Global Constraints

- Water and wine must not change: `"$GODOT" --headless --path . -- --sweep` and `-- --sweep=wine` stay byte-identical to the baselines saved before Task 1 (`$S/sweep_water_base.txt`, `$S/sweep_wine_base.txt`, where `S` is the session scratchpad). Every new `DrinkDef` field defaults to the value that leaves them untouched, and new code branches on it.
- All gameplay stays deterministic and is stepped from `main.tick()`. `randf` is for visuals only (bubbles, foam bumps, spray).
- All existing checks keep passing. Judge a check run by its `check_<name>: OK` lines, not the exit code. Always use `--quit-after`.
- After adding a new script with a `class_name`, run `"$GODOT" --headless --path . --import` before the checks, and commit the generated `.uid` sidecars.
- Colours go in `palette.gd` (`Palette.*`), never literals in game code.
- Spec values: price **150**; `unlock_round` **3**; coins start **20 / 12 / 6**, spill **12**; bottle `full_volume` = **1.05 × target ± 1 %**; a finger = **10 world px**; glass tilt about **35° → 15°**; the tilt grace is **0.25 s**; DRINKS teasers go from **5 → 4**; the BEER upgrades section has **2** blacked-out lines.
- Shell: `GODOT="/Users/mihai/Godot games/Godot.app/Contents/MacOS/Godot"` (quoted, the path has a space). `CHECK() { "$GODOT" --headless --path . --quit-after 900 --script res://tools/run_check.gd -- --check=$1 2>&1 | grep -E "check_|FAIL|outside|SCRIPT ERROR|Parse Error"; }`

## Review Focus

1. **A beer serve when the bottle runs dry mid-glass.** The auto-refill uses the ordinary quick return, and the next glass still gets its own new bottle. Pinned in Task 2 (quick refill swing) and Task 7 (bottle per glass after a refill).
2. **Pressing DOWN with an already full beer glass.** The glass tips, the room shrinks, and foam runs over as a spill rather than vanishing silently. Pinned in Task 5 (`max_liquid` at tilt) and Task 4 (foam spills first).
3. **The tilt switching back to 0 while parcels are still in flight.** Nothing is lost and nothing lands outside the glass. Pinned in Task 6 (conservation across a full pour and release).
4. **Buying beer under `--shop` before any round, or with enough coins before round 3.** It is refused and printed blacked out. Pinned in Task 1.
5. **A drink change to or from beer during LAST_CALL.** The last call waits for the glass to come upright, so a tipped glass is never auto-served mid-pour. Pinned in Task 6.

### Task 3: The foam model

**Files:**
- Create: `foam.gd`, `tools/checks/check_foam.gd`
- Modify: `drink_def.gd` (new Foam group), `drinks/beer.tres`

**Interfaces:**
- Produces: `DrinkDef.has_foam() -> bool` (`foam_share_fast > 0.0`) and these `@export` values, all defaulting to no foam: `foam_share_slow := 0.0`, `foam_share_fast := 0.0` (share of landing beer that turns into foam at a trickle / at full speed), `foam_rate_slow := 150.0`, `foam_rate_fast := 900.0` (landing rates in px²/s; linear between), `foam_wet_share := 0.2`, `foam_dry_share := 0.05` (beer per px² of fresh / drained foam), `foam_drain_time := 1.2`, `foam_collapse_time := 40.0` (s). Beer: slow 0.02, fast 0.25, the rest as the defaults.
- `class_name Foam extends RefCounted`:
  - `const FINGER := 10.0` (world px)
  - `const RATE_TIME := 0.2` (s, the landing-rate smoothing)
  - `var volume := 0.0` (the room it takes, px²); `var beer := 0.0` (beer held in it); `var rate := 0.0` (smoothed landing rate)
  - `func _init(d: DrinkDef)`
  - `func share(r: float) -> float`: the share of landing beer that becomes foam at rate `r`
  - `func land(vol: float) -> float`: takes `vol` of landing beer and returns the part that goes straight into the liquid. The rest goes into `beer`, and `volume` grows by it ÷ `foam_wet_share`. It uses `rate` as of the last `step`.
  - `func step(dt: float) -> float`: updates `rate` from what landed since the last step, drains and collapses, and returns the beer released into the liquid
  - `func spill(room: float) -> float`: foam beyond `room` (px² of space left above the liquid, may be ≤ 0) runs over. It is removed and the beer it held is returned.

- [ ] **Step 3: Implement** `foam.gd` and the `DrinkDef` Foam group, then set beer's values. `step(dt)`:

```gdscript
rate += (_landed / dt - rate) * (1.0 - exp(-dt / RATE_TIME))
_landed = 0.0
var out := 0.0
var wet := beer - volume * _def.foam_dry_share          # drains toward dry foam
if wet > 0.0:
	var d := wet * (1.0 - exp(-dt / _def.foam_drain_time))
	beer -= d
	out += d
if volume > 0.0:                                        # the head collapses slowly
	var c := volume * (1.0 - exp(-dt / _def.foam_collapse_time))
	var held := beer * c / volume
	volume -= c
	beer -= held
	out += held
if volume < 0.05:                                       # the last wisp
	out += beer
	volume = 0.0
	beer = 0.0
return out
```

func _round_of(d: DrinkDef, seed_value: int) -> Dictionary:
	GameState.reset_session(seed_value)
	GameState.owned_drinks.append(d)
	GameState.menu.assign([d])
	main.start_round()
	var pilot := Autopilot.new()
	var pops := [0]
	var count := func(_a: Vector2, _v: Vector2, _c: Color) -> void: pops[0] += 1
	main.pourer.popped.connect(count)
	var t := 0.0
	while main.phase != Main.Phase.SHOP and t < 60.0:
		var dec := pilot.decide(main)
		if dec.serve:
			main.request_serve()
		main.tick(DT, dec.hold)
		t += DT
	main.pourer.popped.disconnect(count)
	return {"results": main.results.duplicate(), "coins": main.round_stats.coins, "pops": pops[0]}

func _beer_round_with_autopilot() -> void:
	var r := _round_of(GameState.BEER, 5)
	var good := r.results.filter(func(x: Dictionary) -> bool: return x.band == Scoring.PERFECT or x.band == Scoring.GOOD)
	var spills := r.results.filter(func(x: Dictionary) -> bool: return x.band == Scoring.SPILL)
	expect(r.results.size() >= 3, "the autopilot serves at least 3 beers in a round (%d)" % r.results.size())
	expect(good.size() * 10 >= r.results.size() * 6 and spills.is_empty(), "...mostly GOOD or better, no spill (%s)" % [r.results.map(func(x: Dictionary) -> StringName: return x.band)])
	expect(r.pops >= r.results.size(), "each beer had its own bottle (%d caps for %d glasses)" % [r.pops, r.results.size()])

func _beer_earns_at_least_wine() -> void:
	var wine := _round_of(GameState.WINE, 5)
	var beer := _round_of(GameState.BEER, 5)
	expect(beer.coins >= wine.coins, "a round of beer earns at least a round of wine (%d vs %d)" % [beer.coins, wine.coins])
